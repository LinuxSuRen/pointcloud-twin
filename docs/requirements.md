# 需求文档（Requirements）

> 状态：v0.1 草案，等待评审。本文档描述 pointcloud-twin 要做什么、不做什么，作为后续实现的验收依据。

## 1. 背景与问题

储能站、工厂等实物场景的数字孪生建设需要一个**真实感强、Web 端可高效加载**的三维底图，以及一套能把**设备粒度实时状态**（SOC、温度、功率、告警）映射到三维场景的机制。

现状痛点：

- 现场三维扫描产出通常是 PCD 点云，Cesium 等 Web 引擎无法直接高效加载；
- 点云本身没有设备语义，无法直接把"1 号电池舱的 SOC"绑定到特定点集上；
- 百万级点云上做逐点动态着色在性能与视觉清晰度上都不可行。

## 2. 目标用户与场景

- 目标用户：数字孪生 / 三维可视化工程师、储能站集成商开发团队。
- 典型场景：储能站现场扫描 → 离线转换出 3D Tiles 底图 + 设备代理体配置 → 部署到 Web 端 → 接入 SCADA/BMS/PCS 实时数据驱动设备状态展示。

## 3. 核心需求（Must Have）

### R1 PCD 点云输入与转换

- R1.1 支持 PCD 输入，至少覆盖 ASCII 与 binary 两种常见编码，字段至少解析 XYZ 坐标，可选解析 intensity/rgb。
- R1.2 支持（可选）输入前预处理：体素降采样（可指定 voxel size）。
- R1.3 转换产出标准 3D Tiles 1.1（GLB/glTF 瓦片）目录（`tileset.json` + 瓦片），可直接被 CesiumJS 加载。

### R2 坐标系（CRS）处理

- R2.1 允许显式指定源坐标系与目标坐标系（如局部 ENU / WGS84），缺省提供合理的局部坐标系假设并在输出元数据中记录。
- R2.2 CRS 信息写入中间 LAS 文件，并传递给切片环节，保证 3D Tiles 落在正确地理位置（或明确的局部原点）。

### R3 设备代理体配置输出

- R3.1 支持输出一份设备代理体配置（JSON/YAML），每条记录至少包含：设备 ID、设备类型、中心坐标、包围盒尺寸、朝向。
- R3.2 设备 ID 规范：人类可读的稳定标识（如 `battery-cluster-01`），作为前端与实时数据流的映射键；禁止用数据库自增 ID 承担该职责。
- R3.3 首版允许**人工标注**方式产出配置（在查看器中交互量取，或直接手写配置文件），自动识别不做要求。

### R4 转换工具形态

- R4.1 提供 CLI（命令行）形态，参数覆盖：输入/输出路径、CRS、降采样 voxel、每瓦片点数、refine 模式、3D Tiles 版本。
- R4.2 转换过程输出结构化进度日志（stdout 分级日志），关键链路出入口有 info 日志。
- R4.3 用户可见错误遵循"稳定错误码 + 普通人能读懂的提示"，技术根因只进日志。

### R5 示例查看器（Vue 3 前端）

- R5.1 提供基于 Vue 3 + Vite + CesiumJS 的示例前端，加载转换产出的 3D Tiles 点云底图。
- R5.2 依据代理体配置渲染 glTF 代理几何体（半透明 / 线框），支持点击选中设备查看详情。
- R5.3 通过 WebSocket 接收实时数据帧（`deviceId → 指标`），驱动代理体颜色 / 透明度 / 悬浮标签；示例中可用模拟数据源演示。
- R5.4 文案与展示分离：状态枚举由前端本地映射表渲染，未知枚举有兜底文案。

## 4. 次要需求（Should Have，首版可降级）

- S1 预处理滤波（离群点去除、裁剪框）。
- S2 代理体配置的图形化标注工具（在查看器内画包围盒并保存为配置）。
- S3 转换任务的 REST/异步任务化封装（大文件上传 + 进度流）。
- S4 批量多站点转换与配置管理。

## 5. 明确不做（Won't Have，首版）

- 不做点云配准 / 拼接（SLAM）、曲面重建、网格化。
- 不做设备自动识别（点云语义分割）。
- 不直接在点云上承载动态状态（不做逐点 / per-point 属性的动态更新）。
- 不内置 SCADA/BMS/PCS 数据采集网关；实时数据接入以 WebSocket 契约为边界。

## 6. 验收标准（对应核心需求）

| 需求 | 验收标准 |
|---|---|
| R1 | 给定一份 ≥ 百万点的 PCD（ASCII 与 binary 各一），CLI 产出可被 CesiumJS 正常加载渲染的 3D Tiles 1.1 目录 |
| R2 | 指定 ENU 原点转换后，瓦片在 Cesium 中地理位置/局部原点正确，输出元数据含 CRS 信息 |
| R3 | 代理体配置可被示例查看器读取并渲染出可交互的设备代理体 |
| R5 | 查看器中代理体随 WebSocket 模拟数据实时变色/更新标签，延迟为感知级（< 1s） |

## 7. 术语表

| 术语 | 说明 |
|---|---|
| PCD | Point Cloud Data，PCL 库定义的点云文件格式 |
| 3D Tiles | OGC 标准，面向 Web 的大规模三维数据流式瓦片格式 |
| glTF | GL Transmission Format，Web 时代的 3D 资产交换格式 |
| 代理体 | 承载设备语义的轻量几何体（半透明盒体/线框），与实时数据绑定 |
| ENU | East-North-Up，以某点为原点的局部东北天坐标系 |
| CRS | Coordinate Reference System，坐标参考系统 |
